# 🚀 ShoaibX - Premium Digital Store & Blog

Welcome to the official repository of **ShoaibX**, a modern, full-stack e-commerce and blogging platform built by **M. Shoaib Memon**.

## 🌟 Features
- **Modern UI/UX:** Dark theme with neon accents and 3D elements.
- **E-Commerce:** Dynamic product listing, filtering, and Amazon integration.
- **Blogging Platform:** Full CMS with search, categories, and dynamic routing.
- **Admin Panel:** Secure dashboard to add, edit, and delete products and blogs.
- **Database:** Fully integrated with Supabase for real-time data.
- **SEO Optimized:** Dynamic metadata, sitemaps, and Google Analytics integration.

## 💻 Tech Stack
- **Frontend:** Next.js 15, React, Tailwind CSS, Framer Motion
- **Backend/Database:** Supabase (PostgreSQL, Auth, Storage)
- **Deployment:** Vercel
- **Analytics:** Vercel Analytics & Google Analytics
